# Intro Animation

Pure-code ASCII intro for Blackwall. No images or video assets are used at
runtime — every frame is computed on an HTML canvas.

- `index.html` — the live, interactive animation. Open it directly in a browser;
  no network connection required (falls back to a system monospace font).
- `blackwall-intro.gif` — short loop used in the main README.
- `blackwall-intro.mp4` — full 30-second sequence.

The animation: an eye opens, the camera dives into the pupil, races through a
data tunnel, and reaches the Blackwall — a pulsing red membrane where the
"BLACKWALL" title resolves out of falling data and a red eye opens in the wall.
